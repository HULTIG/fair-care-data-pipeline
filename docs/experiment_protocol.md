# Revised experiment protocol

This protocol is the contract for the revised study. Historical `results/`
artifacts remain available for audit, but are marked unsuitable for claims in
the revised study until regenerated by the validated runner.

The prediction task is binary prediction at the dataset's documented decision
time: favorable income for Adult, favorable credit risk for German, no
two-year recidivism for COMPAS, and no first-year arrest for NIJ. Each dataset
configuration names the outcome column, favorable label, protected attribute,
comparison groups, predictor allowlist, exclusions, and missing-value tokens in
`configs/default.yaml`. German's status codes are mapped to sex comparison
groups through `privileged_values` and `unprivileged_values`.

The primary utility measures are ROC AUC and balanced accuracy. Fairness is
calculated from the same held-out predictions using prediction-based
demographic parity difference and equal opportunity difference. Per-group
sample, outcome, selection, true-positive, and false-positive counts are
retained. Dataset-label parity is reported separately from prediction-based
fairness. Undefined measures are recorded as unavailable with a reason.

Structural anonymization is evaluated in two ways: the released training
artifact is checked against its mechanism postconditions, while predictive
evaluation uses held-out records and rules fitted from training data. Internal
record identities are used only for split and alignment checks. The current
numeric-noise treatment is a perturbation diagnostic and carries no formal
differential-privacy or re-identification guarantee.

Every run has an immutable run identifier, seed, resolved configuration,
configuration checksum, input checksum, code revision, dirty-state marker,
split checksum, executed-stage record, metric validity, and failure record.
Configurations are compared on paired seeds and common held-out populations.
An aggregate is valid only when all expected successful runs are present.

Evidence validity and policy are separate. Missing or failed required evidence
blocks publication. Valid measurements are then compared with configured
thresholds. The intermediate policy band is publication with a warning; this
choice must be kept consistent in generated results and the manuscript.
